Drop your rank PNGs into this folder with these exact filenames:

  master.png
  amethyst.png
  platinum.png
  gold.png
  silver.png
  bronze.png
  unranked.png

The profile card will auto-render whichever PNG matches the player's rank.
If a file is missing, it falls back to a colored circle with the rank initial.
PNG should be square (any size — gets resized to 72x72 on the card).
Transparent backgrounds (RGBA) work best.
